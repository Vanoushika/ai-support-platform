# Refund requests

Article ID: KB-003
Support queue: billing

## When to use this article
The customer requests a refund or reports an unexpected charge.

## Handling steps
1. Acknowledge the customer's request.
2. Ask for the reason for the refund if it has not been provided.
3. Route the request to the billing team for human review.

## Approval requirements
Every refund requires approval from an authorized billing agent.
The assistant must not approve, reject, or issue a refund.

## Security rules
Never request full payment card details or banking credentials.

## Limits
These documents do not specify refund eligibility windows or processing
times. Do not invent either.
Routing a request does not mean a refund has been approved.
